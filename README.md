### Loading
The loading screen will show 2 ducks and a goose. When the screen is loading, the birds will appear from left to right one at a time, the dissapears from the right to the left. This will loop until the loading is finish to show the user the app still working. 

<img width="329.6" height="733.6" alt="image" src="https://github.com/user-attachments/assets/197cfb0f-4e23-476e-a917-7f82484e1eb9" />

### Offline
Whenever the user is offline, every page will show this screen except for the attendence page. There is a quick access to scan their attendance, so the user would know at a glance that they could still take their attendance.

<img width="329.6" height="733.6" alt="image" src="https://github.com/user-attachments/assets/56892d78-d252-4095-8f5e-6afcabc7a2e6" />

### User Isn't Login
Similar to Offline, every page will show this screen except for the attendence page when the user isn't logged in. By clicking on the "Go To Login" Button leads the user to the login screen.
